# LethalBots NavMesh Project
A Lethal Company Mod made for Lethal Bots to add custom NavMesh links for moons.</br>

[!WARNING]
This mod requires [Lethal Bots](https://thunderstore.io/c/lethal-company/p/TRizzle/LethalBots/) to be installed.

## Installation
1. Download the latest release from Thunderstore.io using your favorite mod manager (e.g., Thunderstore Mod Manager, R2ModMan, Gale, etc.).
2. Make sure to have Lethal Bots installed as this mod does nothing without it.

## Current Updated Moons
### Experimentation
- Bots can now properly use the second ladder on the ship.
- Bots have more dropdown options for the outside stairwell and the pipe.
- Bots can now reach more places on the moon that were previously inaccessible.

### Assurance
- Bots can now access the Fire Exit on the moon.
- Bots can now drop down from the Fire Exit to get back to the ship.
- Bots now consider paths that involve dropping down from the pipes.

### Vow

- Bots can now slide down the cliff to get to the fire exit faster.

### Offense
- Bots can now drop down from the Fire Exit to get back to the ship.
- Bots can now use the Fire Exit and walk along the pipes to get back to the ship.

### Adamance

### Embrion
